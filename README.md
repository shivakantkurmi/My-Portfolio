## 🎨 3D Spatial Portfolio Architecture

This portfolio is an interactive 3D spatial universe engineered from the ground up:

- **Dual-Renderer Engine**:
  - **WebGL Canvas (Three.js r160)**: Renders floating celestial tech sanctuaries, orbital moon lights, volumetric fog, animated particle nebulas, and rotating geometric crystal relics.
  - **CSS3DRenderer**: Bridges 3D space with DOM-rendered UI steles, guaranteeing crisp typography, selectable text, accessible buttons, and custom scrollbars.
- **Diegetic Command Amphitheaters**:
  - **Skills Section**: Central deep-dive stele flanked by two dedicated wings (12 Programming & Full-Stack tablets on the left, 11 Game Dev & AI/Cloud tablets on the right) with a dynamic laser connector beam. Zero visual overlap.
  - **Projects Section**: Central main display console projecting complete project briefs, flanked by 12 surrounding quick-selector tablets with live links.
- **Universal Spatial Navigation**: Smooth OrbitControls supporting free left-click orbit, right-click pan, mouse wheel zoom, and mobile touch pinch-to-zoom.
- **Celestial Lighting Studio**: Interactive drawer with real-time controls for Sun/Moon orbit, exposure, bloom intensity, and five curated presets (*Moonlit Night*, *Golden Dawn*, *Crimson Flame*, *Jade Nirvana*, *High-Clarity Reading*).
- **Procedural Audio Synthesizer**: Web Audio API oscillator synthesizing harmonic chime frequencies for UI interactions and ambient drones.
